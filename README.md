## 作品简介

《转发之前》是一款以校园网络文明为主题的互动式 H5 作品，以"让善意先到场"为核心立意。

作品设置**六个虚构的校园网络现场**：刷屏的停课通知、被裁掉半张的截图、合照发布的前一刻、AI 生成的"未来校园图"、玩笑刷屏以后、免费资料包的隐藏条件，对应信息求证、完整语境、尊重边界、AI 与真实、善意表达、信息守护六类议题。

每个现场采用"**看线索 → 做选择 → 看后续 → 带走行动**"的体验流程：参与者查阅线索后先后做出两次选择，看到行为引发的连锁反应，并获得"下一次可以这样开口"的表达示范。六个现场共 36 条完整分支路线，引导参与者练习**求证、尊重、共情、担当**四种网络素养。

作品还内嵌**发布前自查清单**、温和表达模板，并可生成专属**行动卡**图片。
